# KeepOut 0.01

Local-first private vault MVP built with Next.js.

## Included
- PIN lock screen
- Private contact list
- Private notes
- Local browser storage
- Mobile-first dark UI

## Security note
This MVP is not a second operating system and does not claim to block spyware. Browser localStorage is not sufficient for high-security secrets. Secure messaging is intentionally not enabled until proper authentication and end-to-end encryption are added.

## Run
```bash
npm install
npm run dev
```
